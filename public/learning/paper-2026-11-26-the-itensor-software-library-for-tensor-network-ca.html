ITensor

The ITensor Software Library for Tensor Network Calculations

Matthew Fishman, Steven R. White, E. Miles Stoudenmire · 2020 · 1,416 citations · arXiv:2007.14822

This paper describes a software library for computing with arrays far too large to store, such as the state of a hundred quantum particles, by keeping them as networks of small arrays. Its central design choice is that every array index is an object that knows which vector space it stands for, so products and factorizations are worked out by matching spaces instead of counting axis positions.

I · In 60 Seconds

Problem\(2^{100}\) numbers

A tensor is an array of numbers with any number of indices: a vector has one, a matrix two. The memory cost grows exponentially with the number of indices. The standard example is quantum: a spin is a two-level system whose state is a unit vector in \(\mathbb C^2\), and \(N\) spins together have a state in the tensor product \((\mathbb C^2)^{\otimes N}\). That is an array with \(N\) indices, each taking 2 values, so \(2^N\) numbers. For 100 spins that is about \(1.3\times10^{30}\).

A tensor network avoids storing the big array. It writes it as a product of many small tensors, with sums over the indices they share (each such sum is a contraction). The programming is the hard part. In an ordinary array library an index is only a position (first axis, second axis), so every product makes you track which axis of which array pairs with which, and transpose to match. One slip gives a wrong answer with no error message.

Ideaindices with identity

ITensor (“intelligent tensor”) is a library, written first in C++ and then again in the Julia programming language, built around one object: the Index. An Index has a dimension and a unique ID number, and it stands for one specific vector space. Two indices created separately are different even if their dimensions agree.

A tensor is then defined by its set of indices, in no particular order. Writing A * B sums over exactly the indices the two tensors share. To factor a tensor you name which indices play the role of rows. Indices can also carry symmetry labels, and then the library stores only the blocks a symmetry allows to be non-zero. On top of this sit ready-made algorithms for chains of tensors.

Resultabout 20 lines

The paper's showcase is about 20 lines of code. It finds the lowest eigenvalue of a \(2^{100}\times2^{100}\) Hermitian matrix: the energy operator of 100 spins in a row, each interacting with its neighbours. Five passes of the algorithm, a few seconds each, give \(-44.12774\) with the state stored as a chain of 100 small tensors.

Using a symmetry of that operator pays off heavily. On a harder chain, at the same bond dimension of 1,000 (the size of the small tensors), the run drops from about 3,300 seconds to about 170 (one thread, read off the paper's plots). The newer Julia version is on par with or faster than the hand-tuned C++ one in most of the benchmarks shown. About 450 research papers used ITensor between 2009 and 2021.

II · The Linear Algebra

MachineryReshape, then SVD

An index is a vector space, not a position

Take a tensor \(T\) with indices \(i,j,k\) and a matrix \(M\) with indices \(k,n\). Contracting them over the shared index \(k\) gives a tensor \(R\) with the indices left over:

$$R_{ijn}=\sum_{k}T_{ijk}\,M_{kn}.$$

In ITensor this is R = T * M. The library finds \(k\) in both tensors by its ID, wherever it sits in memory. The one operator covers three familiar cases:

No shared indexouter product

Vectors \(v_i\) and \(w_j\) give \(x_{ij}=v_iw_j\), the tensor product \(v\otimes w\).

All indices sharedinner product

\(\sum_{ijk}A_{ijk}B_{kij}\), a single number. The storage order of the indices in \(A\) and \(B\) does not matter.

Some sharedmatrix product

With \(A\) on indices \((i,j)\) and \(B\) on \((k,j)\), a matrix library needs \(AB^{\top}\). Here A * B is already that, and stays correct if someone later stores \(B\) as \((j,k)\).

A linear map from a space to itself needs two indices for the same space, and they must not contract with each other. ITensor gives one of them a prime: \(i'\) is a copy of \(i\) that compares as different. An operator is then a tensor on \((i', i)\), and applying it to a vector on \(i\) leaves a vector on \(i'\).

Any tensor becomes a matrix once you choose the rows

QR and the singular value decomposition (SVD) are defined for matrices. To use them on a tensor \(W\) with indices \(i,j,m,k\), pick a subset to act as rows, say \((j,i)\). Treat that pair as one index of dimension \(d_jd_i\) (the product of the two dimensions) and the rest \((m,k)\) as one column index. This is the canonical identification \(V_j\otimes V_i\cong\mathbb C^{d_jd_i}\), nothing more. The call U,S,V = svd(W,(j,i)) does the regrouping, factors the matrix, and ungroups:

$$W_{(ji),(mk)}=\sum_{a}U_{(ji),a}\;\sigma_a\;V_{a,(mk)},\qquad \sigma_1\ge\sigma_2\ge\dots\ge0 .$$

\(U\) has orthonormal columns, \(V\) has orthonormal rows, and the \(\sigma_a\) are the singular values. The new index \(a\) is created by the call, so U * S * V rebuilds \(W\) with no bookkeeping.

The fact that does the work: truncation error is the discarded tail

Keep only the \(\chi\) largest singular values and call the result \(W_\chi\). By the Eckart–Young theorem this is the best approximation of rank \(\chi\) in the Frobenius norm (root of the sum of squared entries), and the error is exactly what was thrown away:

$$\|W-W_\chi\|_F^2=\sum_{a>\chi}\sigma_a^2 .$$

ITensor exposes this as two knobs. maxdim caps \(\chi\). cutoff drops singular values from the smallest upward for as long as the discarded sum of squares stays under a tolerance such as \(10^{-8}\), so \(\chi\) adapts to the tensor.

Matrix product state: that SVD at every bond

Now the \(2^N\) problem. Let \(\psi\) be the state of \(N\) spins, a tensor with indices \(s_1,\dots,s_N\), each of dimension \(d\) (\(d=2\) for a spin). A matrix product state, MPS for short (also called a tensor train), writes it as a chain:

$$\psi^{s_1s_2\cdots s_N}=\sum_{\alpha_1,\dots,\alpha_{N-1}}A^{s_1}_{\alpha_1}\,A^{s_2}_{\alpha_1\alpha_2}\,A^{s_3}_{\alpha_2\alpha_3}\cdots A^{s_N}_{\alpha_{N-1}} .$$

Each \(A\) is a small tensor with one site index \(s_j\) and one or two bond indices \(\alpha\) shared with its neighbours. For a fixed value of \(s_j\), \(A^{s_j}\) is a matrix, and an entry of \(\psi\) is a product of \(N\) matrices, hence the name. The largest bond dimension, written \(\chi\), sets the cost: at most \(Nd\chi^2\) numbers instead of \(d^N\).

How large must \(\chi\) be? Cut the chain between sites \(j\) and \(j+1\). Group \(s_1,\dots,s_j\) as rows and the rest as columns, so \(\psi\) becomes a \(d^{\,j}\times d^{\,N-j}\) matrix. The chain is exact only if the bond at that cut has dimension at least the rank of this matrix. Truncating the bond to \(\chi\) costs the sum of squares of the dropped singular values, by the callout above. So an MPS is cheap exactly when these cut matrices have fast-decaying singular values. Physicists call that low entanglement between the two halves.

Tiny example: two spins, one cut

For \(N=2\) the state is already a \(2\times2\) matrix \(\Psi\) with entries \(\psi^{s_1s_2}\). Compare

$$\Psi_1=\tfrac12\begin{pmatrix}1&1\\1&1\end{pmatrix},\qquad \Psi_2=\tfrac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}.$$

\(\Psi_1\) has singular values \((1,0)\). It is rank one, \(\Psi_1=uu^{\top}\) with \(u=(1,1)/\sqrt2\), so the state is the product \(u\otimes u\) and bond dimension 1 is exact.

\(\Psi_2\) is \(1/\sqrt2\) times an orthogonal matrix, so its singular values are \((1/\sqrt2,\,1/\sqrt2)\). It needs bond dimension 2, and cutting to 1 discards weight \(\tfrac12\), half the state. One sign separates a state with no entanglement from one with the most two spins can have.

One more piece of structure makes truncation safe. ITensor keeps an MPS in orthogonal form around a chosen centre site: every tensor to its left, reshaped with rows \((\alpha_{j-1},s_j)\) and columns \(\alpha_j\), has orthonormal columns, and mirror-wise on the right. Such maps are isometries, which preserve the Frobenius norm. So the norm of the whole \(d^N\)-entry state equals the norm of the one centre tensor, and the best truncation of that small tensor is the best truncation of the whole state at that bond. The call is orthogonalize!(psi, j), and the library remembers which tensors are already orthogonal so it never redoes work.

The operator, and a giant eigenproblem solved in small pieces

The energy operator of a quantum system is called its Hamiltonian, \(H\): a Hermitian matrix whose eigenvalues are the possible energies. The eigenvector of the smallest eigenvalue is the ground state. The paper's running example is the Heisenberg chain, a basic model of a magnet:

$$H=\sum_{j=1}^{N-1}\Big(S^z_jS^z_{j+1}+\tfrac12S^+_jS^-_{j+1}+\tfrac12S^-_jS^+_{j+1}\Big),\quad S^z=\tfrac12\begin{pmatrix}1&0\\0&-1\end{pmatrix},\ S^+=\begin{pmatrix}0&1\\0&0\end{pmatrix},\ S^-=(S^+)^{\top}.$$

The subscript says which spin a \(2\times2\) matrix acts on: \(S^z_j\) means \(I\otimes\cdots\otimes S^z\otimes\cdots\otimes I\) with \(S^z\) in slot \(j\). So \(H\) is a real symmetric, very sparse \(2^N\times2^N\) matrix. It is stored as a matrix product operator (MPO): the same chain as an MPS, except each tensor has two site indices, \(s_j'\) for the output and \(s_j\) for the input. For this \(H\) the bonds need dimension only 5, whatever \(N\) is. In code you type the three terms of the sum, and a routine called AutoMPO builds the chain, compressing it with SVDs.

The eigenvector is found by DMRG (the density matrix renormalization group, a 1992 algorithm whose name predates the tensor-network view of it). It minimises the Rayleigh quotient \(\langle\psi|H|\psi\rangle/\langle\psi|\psi\rangle\) over matrix product states, two neighbouring tensors at a time:

1 · Freeze all but two tensors\(\psi=Pb\)

Merge the tensors at sites \(j,j+1\) into one tensor \(b\) with at most \(\chi^2d^2\) entries. With the MPS in orthogonal form, the frozen tensors make up a matrix \(P\) with orthonormal columns that embeds \(b\) into the full space.

2 · Solve a small eigenproblem\(P^{\dagger}HP\)

Because \(P^{\dagger}P=I\), the quotient becomes \(b^{\dagger}(P^{\dagger}HP)\,b/b^{\dagger}b\). The matrix \(P^{\dagger}HP\) is Hermitian of size \(\chi^2d^2\). Its lowest eigenvector is found by the Lanczos method, which needs only products of this matrix with a vector, and those are contractions of \(b\) with a few MPO tensors.

3 · Split and truncateSVD

SVD the new \(b\) with rows \((\alpha_{j-1},s_j)\), keep the top \(\chi\) singular values, and move one site along. A full pass down the chain and back is a sweep.

Since \(P\) is an isometry, the smallest eigenvalue of \(P^{\dagger}HP\) is never below that of \(H\). Every energy DMRG reports is an upper bound on the true one. In the paper's 100-spin run the bound moves from \(-44.0625\) after sweep 1 to \(-44.127739883\) after sweep 5, with \(\chi\) allowed to grow from 10 to 200 and settling at 139.

Symmetry makes the tensors block-sparse

Many Hamiltonians conserve something: particle number, or total spin along an axis. In matrix terms, there is a Hermitian operator \(\hat N\) with integer eigenvalues that commutes with \(H\). The eigenvalue is called a quantum number. Each index space then splits as a direct sum of eigenspaces of \(\hat N\), \(V=\bigoplus_qV_q\), and an Index can record that split. The paper's example, Index(QN(0)=>2, QN(1)=>3), is a 5-dimensional space with a 2-dimensional \(q=0\) part and a 3-dimensional \(q=1\) part.

Split a tensor \(T\) into blocks accordingly, with \(T_{q'q}\) mapping \(V_q\) to \(V_{q'}\). ITensor requires every tensor to have a definite flux \(f\), meaning it changes the quantum number by the same amount everywhere:

$$[\hat N,T]=\hat NT-T\hat N=f\,T\quad\Longleftrightarrow\quad T_{q'q}=0\ \text{ unless }\ q'-q=f .$$

The equivalence is one line: the \((q',q)\) block of \(\hat NT-T\hat N\) is \((q'-q)\,T_{q'q}\). Only the allowed blocks are stored. Contraction, QR and SVD run block by block, and blocks can be processed in parallel. (For tensors with more indices, each index is marked as outgoing or incoming, and flux is the sum of outgoing quantum numbers minus incoming ones.)

Tiny example: the paper's operator \(a\)

One site that holds 0 or 1 particles has basis \(|0\rangle,|1\rangle\) and \(\hat N=\operatorname{diag}(0,1)\). The operator that removes a particle is \(a=\begin{pmatrix}0&1\\0&0\end{pmatrix}\).

\(\hat Na=0\) and \(a\hat N=a\), so \([\hat N,a]=-a\): flux \(-1\). Its only allowed block is (row \(q'=0\), column \(q=1\)), and ITensor stores that single number.

The operator that counts particles, \(n=\operatorname{diag}(0,1)\), has flux 0 and lives on the two diagonal blocks.

The Heisenberg \(H\) above commutes with total \(S^z=\sum_jS^z_j\), so it has flux 0 and every tensor in the calculation is block-sparse. That is the source of the 3,300-to-170-second drop quoted earlier.

IV · Cool Things

FindingsTricks worth keeping

A \(2^{100}\)-sized matrix is a \(5\times5\) tablebond dim 5

The paper says the Heisenberg \(H\) is exactly an MPO of bond dimension 5 and leaves the construction to its references. The standard one is a \(5\times5\) matrix whose entries are themselves \(2\times2\) operators, repeated at every site:

$$W=\begin{pmatrix}I&0&0&0&0\\S^+&0&0&0&0\\S^-&0&0&0&0\\S^z&0&0&0&0\\0&\tfrac12S^-&\tfrac12S^+&S^z&I\end{pmatrix}$$

Multiply \(N\) copies as matrices, using \(\otimes\) between entries, and read the bottom-left entry of the product: it is \(H\). The bond index works as the state of a small machine walking along the chain. State 5 means “no term started yet”, states 2 to 4 mean “first half of a term placed, waiting for its partner”, and state 1 means “term finished”. \(W\) is lower triangular, so the machine never goes back.

The gradient is the network with a hole in itmultilinear

A contracted network is linear in each of its tensors separately. So its derivative with respect to one tensor is the same network with that tensor deleted, and the dangling indices left behind are the gradient's indices. With indices that keep their identity, deleting a tensor needs no relabelling. The authors plan to build automatic differentiation on this.

Excited states by a rank-one penaltydeflation

To get the second-lowest eigenvector after finding the lowest, \(\psi_0\), ITensor runs the same algorithm on \(H+w\,|\psi_0\rangle\langle\psi_0|\), where \(|\psi_0\rangle\langle\psi_0|\) is the orthogonal projector onto \(\psi_0\) and \(w>0\) is a weight. This raises \(\psi_0\)'s eigenvalue by \(w\) and leaves every other eigenpair alone, so the old runner-up is now the minimum. The projector is never built: applying it is two inner products of matrix product states.

Every contraction ends as one matrix multiplypermute, reshape

To contract two dense tensors the backend permutes each so the shared indices sit together, reshapes both into matrices, and calls the standard optimised matrix-multiplication routine (from BLAS, the library nearly all numerical software relies on). The permutation costs time proportional to the tensor's size, while the multiply costs more, so for large tensors the reshuffle is nearly free. Block-sparse tensors do this once per pair of matching blocks.

V · If You Remember One Thing

The one thing to remember

If every index remembers which vector space it is, then contracting tensors, reshaping one into a matrix for an SVD, and skipping the blocks a symmetry forbids all become automatic, and a \(2^{100}\)-dimensional eigenproblem reduces to a loop of small SVDs whose discarded singular values tell you exactly what you lost.
