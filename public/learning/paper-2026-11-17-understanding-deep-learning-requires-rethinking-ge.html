Rethinking Generalization

Understanding Deep Learning Requires Rethinking Generalization

Chiyuan Zhang, Samy Bengio, Moritz Hardt et al. · 2016 · arXiv:1611.03530

The paper trains standard image classifiers on photos whose labels have been replaced by random ones, finds that the networks memorise them perfectly, and concludes that the usual theories, which explain good performance on new data by limits on what a model can fit, cannot be what makes these networks work.

I · In 60 Seconds

Problemmore weights than data

A model's generalization error is the gap between its error on the examples it was trained on and its error on fresh examples. Learning theory explains a small gap in one of two ways: the family of models is too limited to fit arbitrary data (measured by quantities like VC dimension or Rademacher complexity), or regularization, an extra penalty or restriction during training such as shrinking the weights, keeps it from doing so.

Image-recognition networks strain both explanations. The small Inception network used here has 1.6 million weights and is trained on 50,000 images, yet it scores well on images it has never seen.

Ideaa randomization test

Keep the network, the optimiser and every setting fixed, and change only the data: replace each training image's label with one drawn uniformly at random, independent of the image. Nothing about the images can predict these labels, so nothing learned from them can carry over to new images. If the model family were too limited to fit arbitrary data, training should fail here.

Result100% train, 9.78% test

It doesn't fail. On CIFAR-10 (50,000 small photos in 10 classes) Inception reaches 100% training accuracy on random labels and 9.78% test accuracy, which is chance. The same network on the true labels, with every regularizer switched off, still scores 85.75% on test images. It even fits pure Gaussian-noise images, and random labels take only a small constant factor longer to fit.

So the same model family can generalise or not depending only on the labels. Any explanation based only on the family, or only on regularization, misses the cause. The paper backs this with a theorem: a two-layer network with \(2n+d\) weights can fit any labels on \(n\) points in \(d\) dimensions.

II · The Linear Algebra

MachineryTriangular systems & min-norm solutions

The paper is mostly experiments, but its three formal pieces are linear algebra: complexity as a correlation with a random sign vector; a lower-triangular matrix that makes memorisation easy; and the row space of the data matrix, which decides which perfect fit gradient descent returns.

1 · A model family as a set of vectors in \(\mathbb R^n\)

Fix the training inputs \(x_1,\dots,x_n\). Each model \(h\) in the family \(\mathcal H\) becomes one vector \((h(x_1),\dots,h(x_n))\in\mathbb R^n\), its predictions on the sample. The empirical Rademacher complexity asks how well the family can align with a random sign vector \(\sigma\in\{\pm1\}^n\) (independent fair coin flips):

$$\hat{\mathfrak R}_n(\mathcal H)=\mathbb E_\sigma\Big[\sup_{h\in\mathcal H}\tfrac1n\textstyle\sum_{i=1}^n\sigma_i\,h(x_i)\Big].$$

Geometrically it is the average width of that set of vectors in a random sign direction. Standard bounds say test error is at most training error plus about \(2\hat{\mathfrak R}_n\) (plus a term shrinking like \(1/\sqrt n\)). The random-label experiment is this definition run literally: if the network can produce every sign pattern, choose \(h(x_i)=\sigma_i\) and \(\hat{\mathfrak R}_n=1\), the maximum for outputs in \([-1,1]\). The bound becomes “error \(\le\) 2”, which says nothing.

2 · Memorising any labels: a triangular system (Theorem 1)

The network has one hidden layer with \(n\) ReLU units (\(\mathrm{ReLU}(s)=\max\{s,0\}\)). All units share one direction \(a\in\mathbb R^d\); unit \(j\) has its own offset \(b_j\) and output weight \(w_j\):

$$c(z)=\sum_{j=1}^n w_j\,\max\{\langle a,z\rangle-b_j,\,0\}, \qquad \#\text{weights}=d+n+n=2n+d .$$

Given \(n\) distinct points \(z_i\in\mathbb R^d\) and any targets \(y\in\mathbb R^n\):

Step 1, project. Pick \(a\) so the numbers \(x_i=\langle a,z_i\rangle\) are distinct. Almost every \(a\) works: the bad ones lie on the finitely many hyperplanes \(\langle a,z_i-z_j\rangle=0\). Relabel so \(x_1<\dots<x_n\).

Step 2, interleave. Put one offset just left of each point: \(b_1<x_1<b_2<x_2<\dots<b_n<x_n\). Unit \(j\) is then “on” at \(x_i\) exactly when \(i\ge j\).

Step 3, solve. The fitting conditions \(c(z_i)=y_i\) are linear in \(w\):

$$Aw=y,\qquad A_{ij}=\max\{x_i-b_j,\,0\}=\begin{cases}x_i-b_j>0 & j\le i\\ 0 & j>i.\end{cases}$$

\(A\) is lower triangular with diagonal entries \(x_i-b_i>0\), so \(\det A=\prod_i(x_i-b_i)\ne0\) and \(w=A^{-1}y\) exists for every \(y\), random labels included. The weights are found by forward substitution. That is the whole proof (the paper's Lemma 1). It also gives depth-\(k\) versions with only \(O(n/k)\) units per layer.

Tiny example, and a subtlety in Lemma 1

\(x=(1,2,3)\), \(b=(0.5,1.5,2.5)\), labels \(y=(1,-1,1)\):

$$A=\begin{pmatrix}0.5&0&0\\1.5&0.5&0\\2.5&1.5&0.5\end{pmatrix},\qquad w=\begin{pmatrix}2\\-8\\16\end{pmatrix}.$$

Forward substitution: \(0.5w_1=1\Rightarrow w_1=2\); \(3-0.5\cdot8=-1\checkmark\); \(5-12+8=1\checkmark\).

The paper says \(A\)'s smallest eigenvalue, \(\min_i(x_i-b_i)\), can be used to bound the weights. Here every eigenvalue is \(0.5\), so \(1/\lambda_{\min}=2\). But \(\|w\|=18\) while \(\|y\|=\sqrt3\), so \(\|A^{-1}\|_2\ge 18/\sqrt3\approx10.4\). \(A\) is far from normal (it doesn't commute with \(A^{\top}\)), and for non-normal matrices eigenvalues don't control the inverse. The smallest singular value does, and it can be much smaller than the smallest eigenvalue. The first interactive shows this gap.

3 · Which perfect fit? The row space decides (Section 5)

Even a linear model has the same puzzle. Let \(X\in\mathbb R^{n\times d}\) be the data matrix (row \(i\) is \(x_i^{\top}\)) with \(d\ge n\) and rank \(n\), and \(y\in\mathbb R^n\) the labels. Then \(Xw=y\) has an affine space of solutions of dimension \(d-n\), all with zero training loss. Which one generalises?

Curvature can't tell. For a loss of the form \(\tfrac1n\sum_i\mathrm{loss}(w^{\top}x_i,y_i)\), the Hessian (matrix of second derivatives) at any exact fit is

$$\nabla^2=\tfrac1n X^{\top}\operatorname{diag}(\beta)\,X,\qquad \beta_i=\partial_z^2\,\mathrm{loss}(z,y_i)\big|_{z=y_i}.$$

It is the same \(d\times d\) PSD matrix at every solution, with rank \(\le n<d\). Its null space is \(\ker X\), the \(d-n\) flat directions along which you can slide between solutions. So “flat minima generalise” can't separate them.

Gradient descent can. Stochastic gradient descent (SGD) updates \(w_{t+1}=w_t-\eta_t e_t x_{i_t}\): step size \(\eta_t\), times the loss's derivative \(e_t\) on the sampled example \(x_{i_t}\), times that example. Every step adds a multiple of a data point. Starting from \(w_0=0\), the iterate stays in the row space of \(X\): \(w=X^{\top}\alpha\). Combined with \(Xw=y\):

$$XX^{\top}\alpha=y,\qquad w^\star=X^{\top}(XX^{\top})^{-1}y=X^{+}y .$$

\(K=XX^{\top}\) is the \(n\times n\) Gram matrix of inner products \(\langle x_i,x_j\rangle\), symmetric positive definite when \(X\) has rank \(n\). \(X^{+}\) is the Moore–Penrose pseudoinverse. The decomposition doing the work is \(\mathbb R^d=\operatorname{row}(X)\oplus\ker X\), an orthogonal sum. Any solution is \(w^\star+v\) with \(v\in\ker X\), and by Pythagoras

$$\|w^\star+v\|^2=\|w^\star\|^2+\|v\|^2,$$

so SGD from zero returns the minimum-norm interpolant without any explicit penalty. That is implicit regularization. Swap \(\langle x_i,x_j\rangle\) for a kernel \(k(x_i,x_j)\) and this is the kernel trick.

Tiny example

\(n=1,\ d=2\): \(x=(1,2)\), \(y=5\). The solutions form the line \(w_1+2w_2=5\). Here \(K=\|x\|^2=5\), \(\alpha=1\), \(w^\star=(1,2)\), \(\|w^\star\|=\sqrt5\). The fit \((5,0)\) is also exact, and \((5,0)=w^\star+(4,-2)\) with \((4,-2)\perp x\): \(25=5+20\). Both have zero training error; SGD from zero lands on \((1,2)\).

This works surprisingly well. Solving \(K\alpha=y\) exactly on MNIST (70,000 handwritten digits; a 30 GB kernel matrix, solved in under 3 minutes with a standard LAPACK call) gives 1.2% test error with no regularization, and 0.6% after a Gabor wavelet transform of the images. But minimum norm isn't the full answer: the wavelet solution has the larger norm (about 390 vs 220) and half the error. Norm only means something relative to a choice of features.

IV · Cool Things

FindingsFrom the paper's tables

A million random labels, memorised95.20%

On ImageNet (1.28 million photos, 1000 classes), Inception V3 with random labels and no regularization reaches 95.20% training accuracy with no retuning, and 0.11% on test images, where chance is 0.1%. It still reaches about 90% with dropout and weight decay switched on.

Regularization is a tuning knob, not the cause85.75 → 89.05

On CIFAR-10, switching on random cropping and weight decay lifts Inception's test accuracy only from 85.75% to 89.05%. On ImageNet, removing all regularizers drops top-1 accuracy from 77.84% to 59.80%, still 600× chance. Data augmentation alone recovers 72.95%: building in known symmetries of images helps more than penalising weights.

Kernels have the same paradoxPD Gram matrix

A Gaussian kernel \(k(x,x')=e^{-\|x-x'\|^2/2s^2}\) has a strictly positive definite Gram matrix on any distinct points, so \(K\alpha=y\) is solvable for every labelling. A convex, well-understood model is just as able to memorise noise, and on MNIST it generalises anyway. The puzzle is not about deep learning; it is about interpolation.

Stability can't see the labelslabel-blind

Uniform stability bounds how much a trained model can change when one training example is swapped. It is defined as a worst case over all datasets, so it is the same for true and random labels. Yet one case generalises and the other doesn't, so any bound built only on it must be loose.

V · If You Remember One Thing

The one thing to remember

A network big enough to fit random labels perfectly still generalises on real ones, so the answer must lie in which of the many perfect fits training picks. In linear models, SGD started from zero stays in the data's row space and picks the minimum-norm one.
