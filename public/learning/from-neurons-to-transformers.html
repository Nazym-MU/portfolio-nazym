A short illustrated history of neural network architectures

From Neurons to Transformers

Eighty years of one argument — should a network pass the signal straight through, or loop it back?

feed-forward ↔ recurrent, and back again

Every architecture from the perceptron to Mamba exists because the one before it hit a specific wall. This page follows that chain, and reads each step through one question: does the network look at its input in a single pass, or does it carry a running memory from one step to the next?

I · In 60 Seconds

Two ways to build a netthe tension

A feed-forward network pushes its input through a stack of layers once and forgets it. Nothing carries over, so every part of the input can be computed at the same time. A recurrent network reads a sequence one item at a time and keeps a running summary of what it has read so far. That gives it memory, but item 500 cannot be processed until item 499 is done.

The pattern1943–2017

Each fix exposed the next limit. Single neurons could only draw straight boundaries. Stacked layers fixed that but were hopeless on images until convolutions. Text needed memory, so loops were added. The loops forgot anything far back, so gates were added. Then the loop itself became the bottleneck, because it can't run in parallel.

Now2017–

The Transformer (2017) removed the loop: every word looks directly at every other word, all at once. The price is that the work grows with the square of the text length. State space models such as Mamba (2023) bring back a running memory whose cost grows only linearly with length, while still training in parallel. The field has now switched sides three times.

II · The Two Regimes

Feed-forward

y = f ( WL … f ( W1 x ) )

Here x is the input vector, y the output, W1 through WL the weight matrices of the L layers, and f a fixed nonlinear function applied entry by entry (a ReLU, or the sigmoid σ, which squashes any number into the range 0 to 1). Without f the whole stack would collapse into one matrix.

One wide enough hidden layer can approximate any continuous function (Cybenko 1989), so the real question was what structure to build in.

Recurrent

ht = f ( Wx xt + Wh ht−1 )

Now the input is a sequence. xt is the item at position t (say, the vector for the t-th word), and ht is the hidden state: a vector the network rewrites at every step as its summary of everything up to t. Wx mixes in the new word, Wh carries the old summary forward.

The same matrices are reused at every step, so any length fits. Training unrolls the loop into a long chain of weight-sharing copies and backpropagates through it: backpropagation through time.

III · The Chain of Walls

FF = feed-forward · R = recurrent

Perceptron · FF1943–1958

A neuron as arithmetic: take a weighted sum of the inputs and output 1 if it clears a threshold, else 0. McCulloch and Pitts showed such units compute logic, with hand-set weights. Rosenblatt added learning: on each mistake, nudge the weights toward the right answer. It provably converges whenever a straight line (a hyperplane) separates the two classes.

XOR wall1969

XOR outputs 1 when exactly one of two inputs is 1. On the unit square its two “yes” corners sit on a diagonal, so no single line separates them. Minsky and Papert proved one layer can't do it. A hidden layer could, but nobody knew how to train weights that never see the answer. Funding dried up: the first AI winter.

Backprop + MLP · FF1970–1986

The blame problem has a clean answer: swap the hard threshold for a smooth function, then run the chain rule backward from the loss. One backward pass gives the gradient for every weight, at roughly the cost of one forward pass (Linnainmaa, Werbos). Rumelhart, Hinton and Williams made it famous as backpropagation, and multi-layer perceptrons (MLPs) became trainable.

CNN · FF1980–2012

A 224×224 colour image is about 150,000 numbers, so a dense layer needs billions of weights and ignores that neighbouring pixels are related. A convolutional net (CNN) slides one small filter across the image, so the same few weights find an edge wherever it appears. Stacked filters build edges into textures into objects. AlexNet (2012) made it win.

RNN · R1986–1990

Text and speech break the feed-forward mould: inputs have no fixed length, and order changes meaning (“dog bites man” vs “man bites dog”). Jordan and Elman added the loop above, giving the recurrent neural network (RNN).

LSTM / GRU · R1997 / 2014

Plain RNNs could not learn links more than a few dozen steps apart (section IV shows why). The long short-term memory (LSTM) adds a protected memory lane with gates controlling it. The gated recurrent unit (GRU) is a lighter version with two gates. The loop stays.

Seq2seq + attention · R2014–2015

Sequence-to-sequence translation: one LSTM (the encoder) reads the source sentence, and its final hidden state, a single vector, is all a second LSTM (the decoder) gets. Long sentences don't fit through that keyhole. Bahdanau et al. let the decoder look back at every encoder state and take a weighted blend, re-chosen per output word. That blend is attention.

Transformer · FF2017

“Attention is all you need”: keep the attention, delete the recurrence. Attention ignores order, so a position vector is added to each word before it goes in. The result runs fully in parallel on GPUs, and it led to BERT, the GPT line, scaling laws and, applied to image patches, ViT.

S4 / Mamba · R2021–2024

State space models put a running memory back in, but a linear one, built so it trains in parallel and doesn't forget. Section IV explains the trick.

IV · Three Walls, Up Close

1 · Vanishing gradients → LSTM

Suppose the loss at step T depends on a word seen at step 1. Backprop through time reaches h1 by the chain rule, one factor per step:

∂hT / ∂h1 = ∏t ∂ht / ∂ht−1

Each factor is a Jacobian, roughly Wh scaled by the slope of f, the same kind of matrix every step. So the product behaves like a power: it dies off or blows up exponentially (Hochreiter 1991, Bengio et al. 1994).

Try it · one factor, forty steps

Pretend each step multiplies the gradient by the same number r. The bars show how much of the signal from step 1 is left after k steps (log scale; the middle line means “unchanged”, faded bars are off the chart).

The LSTM fix

The only stable value is r = 1, and a plain RNN can't hold it. The LSTM adds a second vector, the cell state ct, updated by addition instead of by a matrix multiply:

ct = forget · ct−1 + write · (new content)

Each gate is a vector of numbers between 0 and 1 (a sigmoid output) computed from the current word and the last hidden state, applied entry by entry like a dimmer. Along the cell lane the gradient is multiplied only by the forget gate, which the network can learn to hold near 1: the slider pinned at 1.0. A third gate decides how much of the cell to reveal as ht.

2 · Sequential steps → self-attention

Even with gates, an RNN links word 1 to word 500 through a relay of 499 updates, and none of them can start before the previous one ends. GPUs sit idle.

Self-attention replaces the relay with direct lookups. From each word's vector, three learned matrices produce a query (what this word is looking for), a key (what it offers to be matched on) and a value (what it hands over if chosen). Stacking these for all words gives matrices Q, K and V:

output = softmax( Q K⊤ / √d ) V

QK⊤ is the table of every query dotted with every key. Softmax turns each row into positive weights that sum to 1, and each word's output is that weighted average of the values (d is the key length; dividing by √d keeps scores from saturating). Any two words are now one hop apart, and it is all one matrix product.

3 · Quadratic cost → state space models

That table has one entry per pair of words. With n the sequence length, it has n² entries, so the cost is O(n²): double the context, quadruple the work. Books, codebases and hours of audio get expensive.

A state space model (SSM), borrowed from control theory, goes back to a running state but keeps the update linear:

ht = A ht−1 + B xt,   yt = C ht

A, B and C are learned matrices. With no nonlinearity in the loop, the unrolled output is just the input convolved with the kernel CB, CAB, CA²B, …, computable for all positions at once. S4 (Gu et al., 2021) also chose A so its powers fade slowly: the slider held near 1. Cost is O(n), and generation keeps one fixed-size state.

Mamba (Gu and Dao, 2023) makes A, B and C depend on the current input, so it chooses what to keep. That breaks the convolution, so it trains with a parallel scan instead.
