Feature Hilbert Spaces

Quantum Machine Learning in Feature Hilbert Spaces

Maria Schuld & Nathan Killoran (Xanadu) · 2018 · arXiv:1803.07128

The paper argues that loading data into a quantum state is the same thing a kernel method does: it maps each input into a huge vector space, where the overlap between two states measures how similar the inputs are. It then builds classifiers on that idea, using squeezed light as the example.

I · In 60 Seconds

Problemtwo huge spaces

A kernel method (the support vector machine is the best-known one) classifies data by sending each input into a high-dimensional, sometimes infinite-dimensional, feature space. There a flat boundary, a hyperplane, can separate classes that were tangled in the original space. The method never builds the feature vectors. It needs only the inner product of every pair of them, a similarity score called the kernel.

Quantum computers also work inside enormous spaces without writing them down. The state of \(n\) qubits is a vector of \(2^n\) complex numbers, and one mode of light lives in an infinite-dimensional space. Yet in 2018 quantum machine learning had barely touched kernels. It also had a practical problem: quantum operations are linear, so building the nonlinear models machine learning relies on was awkward.

Ideaencoding = feature map

Preparing a quantum state \(|\phi(x)\rangle\) that depends on an input \(x\) is a feature map: a nonlinear map from inputs into a huge vector space. So the overlap \(\langle\phi(x)|\phi(x')\rangle\) of two such states is automatically a valid kernel, and all of kernel theory applies. The nonlinearity sits in the encoding, so the circuits themselves can stay linear.

That gives two classifiers. Implicit: the quantum device only estimates overlaps, and an ordinary classical support vector machine does the rest. Explicit: a trainable quantum circuit, followed by a measurement, draws the decision boundary directly in the quantum state space.

Resultalways separable

The example encodes each number as the phase of squeezed light, a standard optical state. The paper tests it on three toy 2-D datasets: two concentric rings ("circles"), two interlocking crescents ("moons") and separate clusters ("blobs"). A support vector machine using this kernel scores 0.88/0.92, 0.99/1.00 and 1.00/1.00 (training/test accuracy). A trainable 2-mode optical circuit with 32 parameters reaches 0.99/0.98 on moons.

The paper also proves that this encoding makes the states of any distinct inputs linearly independent. So every labelling of a training set is separable by a hyperplane. A perceptron reaches 100% training accuracy on blobs while test accuracy stays at 0.80. These are simulations: squeezed states can be simulated efficiently on ordinary computers, so the paper is a framework, not a demonstration of quantum advantage.

II · The Linear Algebra

MachineryGram matrices & a Vandermonde

The training data is \(M\) inputs \(x^1,\dots,x^M\) from an input set \(\mathcal X\) (here, vectors in \(\mathbb R^N\)), with labels \(y^m\in\{-1,+1\}\). The feature space \(\mathcal F\) is a complex Hilbert space, and its inner product \(\langle a|b\rangle\) is conjugate-linear in the first slot.

The objects

\(U_\phi(x)\)unitary, depends on x

The feature-embedding circuit. It acts on the all-zero (vacuum) state and produces the feature vector \(|\phi(x)\rangle = U_\phi(x)|0\dots0\rangle\), a unit vector in \(\mathcal F\). The map \(x\mapsto|\phi(x)\rangle\) is nonlinear in \(x\), but every operator applied after it acts linearly on the state.

\(K\in\mathbb C^{M\times M}\)Hermitian PSD

The Gram matrix of the training states, \(K_{mm'}=\kappa(x^m,x^{m'})=\langle\phi(x^m)|\phi(x^{m'})\rangle\). If \(\Phi\) is the operator whose columns are the feature vectors, then \(K=\Phi^\dagger\Phi\), where \(\dagger\) means conjugate transpose. So \(K\) is Hermitian and positive semidefinite, with a unit diagonal because the states are normalised. Its rank is the dimension of the span of the feature vectors.

\(W(\theta)\)trainable unitary

The model circuit, with parameters \(\theta\). Applied to vacuum, it gives \(|w\rangle=W|0\dots0\rangle\), the normal vector of a hyperplane in \(\mathcal F\). The linear model is \(f(x)=\langle w|\phi(x)\rangle\). The decision boundary is where \(|w\rangle\perp|\phi(x)\rangle\).

Two facts carry all the classical theory. First, every feature map gives a kernel: for any coefficients \(c_m\in\mathbb C\),

$$\sum_{m,m'} \bar c_m\, c_{m'}\, K_{mm'} \;=\; \Big\|\sum_m c_m\,|\phi(x^m)\rangle\Big\|^2 \;\ge 0,$$

with equality only if \(\sum_m c_m|\phi(x^m)\rangle=0\). So \(K\) is positive definite exactly when the feature vectors are linearly independent. Remember this; it is the fact the whole paper turns on.

Second, the representer theorem: when you fit a model by minimising a loss plus a penalty that grows with \(\|f\|\), the best \(f\) is a combination of kernels centred on the training points,

$$f^*(x)=\sum_{m=1}^{M}\alpha_m\,\kappa(x,x^m).$$

Training only has to find the \(M\) numbers \(\alpha_m\), and it only ever sees \(K\). So the quantum device's whole job is to estimate entries of \(K\) (for example with a swap test, a short circuit whose measurement statistics give \(|\langle a|b\rangle|^2\)). That is the implicit approach.

Tensor products multiply kernels

If each feature gets its own subsystem, the state is a tensor product. The rule \(\langle a\otimes b\,|\,c\otimes d\rangle=\langle a|c\rangle\langle b|d\rangle\) turns the kernel into a product. The paper's catalogue of standard encodings:

bit string \(\to\) basis state \(|i\rangle\)\(\kappa=\delta_{ij}\)
unit \(x\in\mathbb R^{2^n}\) \(\to\) amplitudes \(\sum_i x_i|i\rangle\)\(\kappa=x^{\top}x'\)
\(d\) copies \(|\psi_x\rangle^{\otimes d}\)\(\kappa=(x^{\top}x')^d\)
\(\bigotimes_i(\cos x_i,\ \sin x_i)\)\(\kappa=\prod_i\cos(x_i-x_i')\)
Tiny example: product encoding, N = 2 features

\(x=(0,\tfrac\pi4)\mapsto\binom{1}{0}\otimes\binom{.707}{.707}=(.707,\ .707,\ 0,\ 0)\).

\(x'=(\tfrac\pi3,\tfrac\pi4)\mapsto\binom{.5}{.866}\otimes\binom{.707}{.707}=(.354,\ .354,\ .612,\ .612)\).

Inner product in \(\mathbb R^4\): \(.707\cdot.354\cdot2=0.5=\cos\tfrac\pi3\cdot\cos 0\). With \(N\) features the vectors live in \(\mathbb R^{2^N}\), yet the kernel costs \(N\) cosines.

The squeezing feature map

A mode of light has Fock space \(\ell^2(\mathbb N)\) as its state space. Its orthonormal basis \(|n\rangle\) means "exactly \(n\) photons". The annihilation operator \(\hat a|n\rangle=\sqrt n\,|n-1\rangle\) is a weighted backward shift, and its adjoint \(\hat a^\dagger\) is the matching forward shift. The squeeze operator

$$S(z)=\exp\!\big[\tfrac12(\bar z\,\hat a^2-z\,\hat a^{\dagger2})\big],\qquad z=re^{i\varphi},$$

is unitary, because its exponent is anti-Hermitian. It moves photons only in pairs, so the squeezed vacuum \(S(z)|0\rangle\) lives on even levels only:

$$|(r,\varphi)\rangle=\frac{1}{\sqrt{\cosh r}}\sum_{n=0}^{\infty}\frac{\sqrt{(2n)!}}{2^n n!}\,\big(-e^{i\varphi}\tanh r\big)^n\,|2n\rangle.$$

The feature map fixes the squeezing strength \(r=c\) (a hyperparameter) and writes the input into the phase: \(x\mapsto|(c,x)\rangle\). A vector input \(x\in\mathbb R^N\) uses one mode per feature, \(|(c,x)\rangle=\bigotimes_i|(c,x_i)\rangle\). Write \(t=\tanh c\). Taking the inner product term by term and using \(\sum_n\binom{2n}{n}(w/4)^n=(1-w)^{-1/2}\) gives the kernel in closed form:

$$\kappa(x,x')=\prod_{i=1}^{N}\frac{\operatorname{sech}c}{\sqrt{1-e^{i(x_i'-x_i)}\,t^2}}.$$

Each factor depends only on the phase difference \(x_i'-x_i\), taken mod \(2\pi\). It equals 1 when the phases agree and is smallest when they differ by \(\pi\). Larger \(c\) makes the peak narrower.

Tiny example: c = ln 3, so tanh c = 0.8 and sech c = 0.6

\(|(c,0)\rangle\approx 0.775|0\rangle-0.438|2\rangle+0.304|4\rangle-0.222|6\rangle+\cdots\). Using phase \(\pi\) flips the sign of every other term.

\(\kappa(0,\pi)=0.6/\sqrt{1+0.64}=0.469\). The four terms shown already give \(0.600-0.192+0.092-0.049=0.452\).

The fact that does the work: a Vandermonde determinant

The paper proves that distinct phases \(\varphi^1,\dots,\varphi^M\) give linearly independent squeezed states. Stack the states as rows of a matrix \(\mathsf M\) (size \(M\times\infty\)), with entries in the Fock basis. Then scale rows by \(D_1=\operatorname{diag}(\sqrt{\cosh r_j})\) and columns by \(D_2=\operatorname{diag}\big(n!/\sqrt{(2n)!}\big)\). Both are invertible diagonal matrices, so neither changes the rank. What remains is a pure power pattern:

$$V=D_1\,\mathsf M\,D_2,\qquad V_{jn}=z_j^{\,n},\qquad z_j=-\tfrac12\,e^{i\varphi_j}\tanh c .$$

Keep only the first \(M\) columns, \(n=0,\dots,M-1\). That square block is a Vandermonde matrix, with

$$\det V_{M\times M}=\prod_{jThe \(z_j\) sit on a circle of radius \(\tfrac12\tanh c\) at angles \(\varphi_j+\pi\). They are distinct exactly when the phases are distinct mod \(2\pi\), which is the only way two inputs can collide. An invertible \(M\times M\) block means \(\mathsf M\) has full row rank, so the states are independent.

the paper writes det V > 0; the entries are complex, so the right statement is det V ≠ 0.

Tiny example: three phases, tanh c = 0.8

\(\varphi=0,\tfrac\pi2,\pi\) give nodes \(z=-0.4,\ -0.4i,\ 0.4\), and

$$V=\begin{pmatrix}1&-0.4&0.16\\1&-0.4i&-0.16\\1&0.4&0.16\end{pmatrix},$$

\(\det V=(0.4-0.4i)(0.8)(0.4+0.4i)=0.8\cdot0.32=0.256\neq0\). Nudge \(\varphi_2\) toward \(0\) and the first chord \(z_2-z_1\) shrinks: the determinant goes to zero continuously, and the two states become nearly parallel.

Several modes. If \(\{v(s)\}\) is a linearly independent family, so is every family of tensor products \(v(s_1)\otimes\cdots\otimes v(s_N)\) indexed by distinct tuples \((s_1,\dots,s_N)\). So distinct input vectors still give independent states. The paper argues this from the overlaps being nonzero, which is not enough on its own; the tensor-product fact is what makes it true.

Why independence means every labelling is separable

Independent features mean \(K\) is invertible. Look for \(|w\rangle=\sum_m\beta_m|\phi(x^m)\rangle\). The conditions \(f(x^k)=\langle w|\phi(x^k)\rangle=y^k\) for all \(k\) form the \(M\times M\) system \(\sum_m\bar\beta_m K_{mk}=y^k\). Its matrix is \(K^{\top}\), which is invertible, so for any labels \(y\) there is a \(|w\rangle\) hitting them exactly. Then \(\operatorname{sign}\operatorname{Re} f(x^m)=y^m\) for every \(m\).

This is the Gram-matrix form of the paper's Appendix C rank argument, and it is why the perceptron in Fock space always reaches 100% training accuracy.

The explicit classifier: a linear functional on density operators

For a 2-D input, each coordinate squeezes its own mode. Then the trainable unitary \(W(\theta)\) acts, and a photon counter on each mode reads out photon numbers. The paper's two class scores are the probabilities of seeing photon counts \((2,0)\) and \((0,2)\), normalised to sum to one. Each probability is a quadratic form in the state:

$$o_0=\big|\langle 2,0|\,W(\theta)\,|\phi(x)\rangle\big|^2=\operatorname{Tr}\!\big(O_\theta\,\rho_x\big),\qquad O_\theta=W^\dagger\,|2,0\rangle\langle2,0|\,W,\quad \rho_x=|\phi(x)\rangle\langle\phi(x)|.$$

\(O_\theta\) is a rank-one orthogonal projector, rotated by the unitary. So the score is linear in the density operator \(\rho_x\), the rank-one projector onto the feature state. Only the final normalisation \(o_0/(o_0+o_1)\) is nonlinear.

Each block of \(W\) is a beamsplitter (\(e^{u(e^{iv}\hat a_1^\dagger\hat a_2-e^{-iv}\hat a_1\hat a_2^\dagger)}\), which mixes the modes) followed by one-mode gates whose generators are polynomials of degree 1, 2 and 3 in the position-like operator \(\hat x\) (displacement, quadratic phase, cubic phase). The cubic gate is the only non-Gaussian gate in the set, and it is what makes such a circuit hard to simulate classically.

IV · Cool Things

FindingsAnd one derivation

The Gram spectrum is the photon distribution, foldedcirculant

This one is derived for this page; it is not in the paper. The kernel depends only on \(x'-x\), so for evenly spaced phases \(K\) is a Hermitian circulant matrix, diagonalised by the discrete Fourier transform. Expanding \(\kappa\) as a Fourier series in the phase difference, the coefficient of \(e^{in\Delta}\) is \(p_n=|\langle 2n|(c,x)\rangle|^2\), the probability of finding \(2n\) photons. That gives

$$\lambda_m=N\!\!\sum_{n\equiv m\ (\mathrm{mod}\ N)}\!\! p_n,\qquad m=0,\dots,N-1.$$

Every eigenvalue is \(N\) times a sum of positive probabilities, so \(K\succ0\) can be read off directly, and \(\sum_m\lambda_m=N\sum_n p_n=N\). Weak squeezing puts nearly all probability on \(n=0\), so one eigenvalue is about \(N\) and the rest are tiny: exactly what interactive 1 shows.

A huge Hilbert space is not an advantageGaussian = easy

The squeezing kernel lives in infinite dimensions, yet it is a one-line formula; the paper's own simulations evaluate it classically. Squeezed states are Gaussian states, and those can be simulated efficiently on ordinary computers. A quantum kernel only earns its keep if \(\langle0|V_\phi(x)^\dagger V_\phi(x')|0\rangle\) is hard to compute classically, for example when the circuit \(V_\phi\) includes a non-Gaussian cubic phase gate. The paper leaves open which such kernels are also useful.

\(|\kappa|^2\) is a kernel tooSchur product

Hardware estimates \(|\langle\phi(x)|\phi(x')\rangle|^2\), not the complex overlap. That is still a valid kernel, in two ways. Entrywise, its Gram matrix is \(K\circ\bar K\), the elementwise product of two positive definite matrices, which is positive definite by the Schur product theorem. As a feature map, it equals \(\operatorname{Tr}(\rho_x\rho_{x'})\), the Hilbert–Schmidt inner product of density operators. The real feature vector is \(\rho_x\), the same object the explicit classifier is linear in.

A non-normal operator gives the Gaussian kernelcoherent states

Every complex number \(\alpha\) is an eigenvalue of the annihilation operator \(\hat a\), with eigenvector the coherent state \(|\alpha\rangle\). Because \(\hat a\) is not normal, eigenvectors for different eigenvalues need not be orthogonal: \(|\langle\alpha|\beta\rangle|^2=e^{-|\alpha-\beta|^2}\), the Gaussian (radial basis function) kernel. The paper's appendix contrasts this with the position operator, whose generalised eigenvectors are orthogonal. There the "kernel" is a Dirac delta, which is not square-integrable, so \(L^2\) is not a reproducing-kernel Hilbert space.

V · If You Remember One Thing

The one thing to remember

Encoding data into quantum states is a feature map, so state overlaps form a positive semidefinite Gram matrix that any kernel method can use. For squeezed states a Vandermonde determinant makes that matrix strictly positive definite, so every labelling is separable: lots of expressive power, but by itself neither generalisation nor quantum advantage.
