State Space Duality

Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality

Tri Dao and Albert Gu · 2024 · arXiv:2405.21060

The paper shows that a recurrent sequence model with a fixed-size memory and a softmax-free version of attention are two algorithms for multiplying by the same lower-triangular matrix. That matrix has a special structure: every block below the diagonal is low-rank. The authors then use this structure to build Mamba-2, which is faster than its predecessor.

I · In 60 Seconds

Problemtwo camps, two costs

A language model reads a sequence of tokens (word pieces) and mixes information between positions. Transformers do this mixing with attention, which scores every pair of positions. For a sequence of length \(T\), training cost grows like \(T^2\). While generating text, the model has to keep a cache of everything it has seen, and that cache grows with \(T\).

State space models (SSMs) take the other approach. They are recurrent: they carry a fixed-size memory (the state) and update it once per token, so their cost is linear in \(T\). Mamba (2023), an SSM, matched Transformers at small and medium scale. But its update is a sequential scan, which can't use the GPU's matrix-multiply units (tensor cores) that make Transformers fast. Its cost also grows with the size of the state, which pushed it toward small states.

Ideaone matrix, two algorithms

Both models are linear maps along the time axis: output \(y = Mx\) for a \(T\times T\) lower-triangular matrix \(M\). For an SSM, every block of \(M\) on or below the diagonal has rank at most the state size. Matrices with this property are called semiseparable. If the SSM's memory decays by a single number per step, \(M\) is exactly a masked attention matrix with the softmax removed.

Running the recurrence and running attention are then just two ways to multiply by \(M\): one costs time linear in \(T\), the other quadratic. The paper's algorithm (SSD, for state space duality) cuts \(M\) into blocks. It handles the blocks on the diagonal attention-style and the low-rank blocks below them through the state. Almost all of the work becomes ordinary matrix multiplication.

Result2–8× faster

SSD runs 2–8× faster than Mamba's optimized scan and allows states 8× larger with little slowdown. It overtakes FlashAttention-2 (a highly optimized softmax attention) at a sequence length of about 2,000 tokens and is 6× faster at about 16,000.

The resulting model, Mamba-2, has 2.7 billion weights and was trained on 300 billion tokens of the Pile (a public text corpus). Its average accuracy on seven standard zero-shot benchmarks is 60.2. Mamba-2.8B scores 59.9, and Pythia-6.9B scores 58.3. Pythia is a Transformer family trained on the same data, and this one is more than twice Mamba-2's size.

II · The Linear Algebra

MachinerySemiseparable matrices

Take one channel of the input: a sequence of numbers \(x_0,\dots,x_{T-1}\), one per token. The SSM keeps a state vector \(h_t\in\mathbb R^N\), where \(N\) is the state size (16 in Mamba, 64 or more in Mamba-2). Each step uses three time-dependent parameters: \(A_t\in\mathbb R^{N\times N}\) (how the old state carries over), \(B_t\in\mathbb R^{N}\) (how the new input is written into the state) and \(C_t\in\mathbb R^{N}\) (how the output is read out).

$$h_t = A_t\,h_{t-1} + B_t\,x_t,\qquad y_t = C_t^{\top}h_t .$$

In Mamba, \(A_t,B_t,C_t\) are computed from the input itself. This makes the model selective: it can choose what to store and what to forget. So the full model is nonlinear. Once those parameters are fixed, though, the map from \(x\) to \(y\) is linear, and that linear map is the object of study.

Unroll the recurrence: the matrix \(M\)

Starting from \(h_{-1}=0\) and substituting repeatedly gives

$$y_t=\sum_{s\le t} C_t^{\top}A_tA_{t-1}\cdots A_{s+1}B_s\,x_s \quad\Longrightarrow\quad y=Mx,\qquad M_{ts}=\begin{cases}C_t^{\top}A_t\cdots A_{s+1}B_s & t\ge s\\[2pt] 0 & t<s.\end{cases}$$

\(M\) is \(T\times T\) and lower triangular, because output \(t\) never sees future inputs. In the model, the input has \(P\) channels (the head dimension, 64 or 128 in Mamba-2), stacked as a \(T\times P\) matrix \(X\). All \(P\) channels share the same \(M\), so the layer computes \(Y = MX\).

The fact doing the work: every block below the diagonal has rank ≤ N

Take any block of \(M\) that lies entirely on or below the diagonal: rows \(r_0,\dots,r_1\) and columns \(c_0,\dots,c_1\) with \(r_0\ge c_1\). Its entries factor through the moment \(c_1\):

$$M_{\text{rows},\text{cols}}= \underbrace{\begin{pmatrix}C_{r_0}^{\top}A_{r_0}\cdots A_{c_1+1}\\ \vdots\\ C_{r_1}^{\top}A_{r_1}\cdots A_{c_1+1}\end{pmatrix}}_{\text{rows}\times N} \underbrace{\begin{pmatrix}A_{c_1}\cdots A_{c_0+1}B_{c_0} & \cdots & B_{c_1}\end{pmatrix}}_{N\times\text{cols}} .$$

The right factor writes the earlier inputs into the state \(h_{c_1}\), and the left factor reads the later outputs from it. Every path from past to future passes through one \(N\)-dimensional vector, so the block has rank at most \(N\).

A lower-triangular matrix with this property is called \(N\)-semiseparable. The converse also holds (Prop. 3.4): every \(N\)-semiseparable matrix comes from some SSM with state size \(N\), and can be stored in \(O(NT)\) numbers instead of \(T^2\). So an SSM with state size \(N\) and an \(N\)-semiseparable matrix are the same object (Theorem 3.5).

Tiny example: N = 1, T = 3

Take \(A_t = a_t\) as scalars and \(B_t=C_t=1\), with \(a_1=0.5,\ a_2=0.8\). Then \(M_{ts}=a_t\cdots a_{s+1}\):

$$M=\begin{pmatrix}1&0&0\\0.5&1&0\\0.4&0.8&1\end{pmatrix},\qquad \begin{pmatrix}0.5&1\\0.4&0.8\end{pmatrix}=\begin{pmatrix}1\\0.8\end{pmatrix}\begin{pmatrix}0.5&1\end{pmatrix}.$$

The \(2\times2\) block in rows 1–2 and columns 0–1 has determinant \(0.4-0.4=0\), so its rank is 1 even though it touches the diagonal.

Multiplying by \(M\) needs no \(T^2\) work, because \(M^{-1}\) is bidiagonal:

$$M^{-1}=\begin{pmatrix}1&0&0\\-0.5&1&0\\0&-0.8&1\end{pmatrix} \quad\Longleftrightarrow\quad y_t = a_t\,y_{t-1}+x_t .$$

For \(x=(1,1,1)\): \(y_0 = 1\), \(y_1 = 0.5\cdot1+1 = 1.5\), \(y_2 = 0.8\cdot1.5+1 = 2.2\). That matches the last row of \(M\) applied to \(x\): \(0.4+0.8+1\). Running the recurrence is forward substitution with a bidiagonal matrix.

Shrink \(A_t\) to a scalar: out comes attention

Mamba-2 restricts the transition to a scalar times the identity, \(A_t=a_tI_N\) with \(a_t\in[0,1]\). Mamba used a diagonal \(A_t\). Write \(a_{t:s}=a_ta_{t-1}\cdots a_{s+1}\), the product of the decays after step \(s\) up to step \(t\) (equal to 1 when \(t=s\)). Stack the \(C_t^{\top}\) as rows of \(C\in\mathbb R^{T\times N}\), and the \(B_s^{\top}\) likewise into \(B\). The scalars then pull out of each entry:

$$M_{ts}=\underbrace{a_{t:s}}_{L_{ts}}\cdot\underbrace{C_t^{\top}B_s}_{(CB^{\top})_{ts}} \qquad\Longrightarrow\qquad M = L\circ (CB^{\top}),$$

Here \(\circ\) is the entrywise (Hadamard) product, and \(L\) is the lower-triangular mask with \(L_{ts}=a_{t:s}\), a 1-semiseparable matrix like the tiny example. Compare masked attention, \(Y=(L\circ QK^{\top})V\), where \(Q,K,V\) are the queries, keys and values. The two have the same form, with \(C\leftrightarrow Q\), \(B\leftrightarrow K\), \(X\leftrightarrow V\). The softmax is gone, and the mask \(L\) takes the role that positional encodings play in a Transformer.

The structure also checks out from the attention side. \(CB^{\top}\) is a \(T\times T\) Gram matrix of rank at most \(N\), and for any two matrices of the same shape, \(\operatorname{rank}(R\circ S)\le\operatorname{rank}R\cdot\operatorname{rank}S\). So every block of \(L\circ CB^{\top}\) below the diagonal has rank at most \(1\cdot N\).

Familiar masks are special cases. With \(a_t=1\), \(L\) is the all-ones lower triangle, and you get linear attention, whose recurrence is a cumulative sum. A constant \(a_t=\gamma\) gives the Toeplitz decay \(\gamma^{t-s}\) (RetNet). An input-dependent \(a_t\) gives SSD.

Same function, two contraction orders

The quadratic order is attention. Form the \(T\times T\) matrix, mask it, and apply it:

$$G=CB^{\top},\qquad M=L\circ G,\qquad Y=MX\qquad\big(O(T^2N+T^2P)\big).$$

The linear order is the recurrence. Write \(x_s\in\mathbb R^P\) for row \(s\) of \(X\). First expand each input into a \(P\times N\) outer product, then apply \(L\) along time, then contract:

$$Z_s=x_sB_s^{\top},\qquad H_t=a_tH_{t-1}+Z_t,\qquad y_t=H_tC_t\qquad\big(O(TPN)\big).$$

The middle step is multiplication by \(L\) for each of the \(PN\) entries of the state \(H_t\). It is linear in \(T\) only because \(L^{-1}\) is bidiagonal.

Theorem 5.2: fast autoregressive attention must be an SSM

Suppose a masked attention can generate each new output from a fixed number \(k\) of past outputs: \(y_t=\mu_tx_t+\ell_{t1}y_{t-1}+\dots+\ell_{tk}y_{t-k}\). Then \(L^{-1}\) is lower triangular and banded with bandwidth \(k+1\). Banded matrices are semiseparable, and the inverse of an \(N\)-semiseparable matrix is at most \((N+1)\)-semiseparable (a consequence of the Woodbury identity). So \(L\) is semiseparable, which by Theorem 3.5 makes it an SSM. Any efficient causal attention of this kind is a state space model in disguise.

The SSD algorithm: a block decomposition of \(M\)

Cut the sequence into chunks of length \(Q\). This tiles \(M\) into \(Q\times Q\) blocks.

For chunks \(j>i\), the block \(M^{(j,i)}\) factors exactly like the callout above:

$$M^{(j,i)}=\underbrace{\big[a_{t:jQ-1}\,C_t^{\top}\big]_{t\in\text{chunk }j}}_{Q\times N}\;\cdot\;\underbrace{a_{jQ-1:(i+1)Q-1}}_{\text{scalar}}\;\cdot\;\underbrace{\big[a_{(i+1)Q-1:s}\,B_s^{\top}\big]_{s\in\text{chunk }i}^{\top}}_{N\times Q}.$$

These three factors give four steps:

1 · Diagonal blocks\((Q\times N)(N\times Q)\)

Each chunk's output from its own inputs, using quadratic attention inside the chunk. All chunks run in parallel.

2 · Right factors\((N\times Q)(Q\times P)\)

Each chunk's final state, assuming it started from zero.

3 · Centre factorsscan of length \(T/Q\)

The true state at each chunk boundary, from \(H_j=(\text{decay over chunk } j)\,H_{j-1}+S_j\), where \(S_j\) is chunk \(j\)'s own final state from step 2. This is a 1-semiseparable multiplication again, but \(Q\) times shorter.

4 · Left factors\((Q\times N)(N\times P)\)

What each chunk's outputs receive from the incoming state.

With \(N=P=Q\) (64 in practice), every heavy step is a batch of \(N\times N\) matrix products: \(O(TN^2)\) arithmetic, \(O(TN)\) memory, all on tensor cores. Table from §6.3, assuming \(P=N\):

IV · Cool Things

FindingsFrom the paper

Even a dense SSM is cheapTheorem 3.7

With fully dense \(A_t\), just writing the parameters down takes \(TN^2\) numbers. Yet because the matrix is \(N\)-semiseparable, it compresses to \(O(TN)\) numbers. So after a preprocessing step, any SSM runs in \(O(TN)\) time, matching the lower bound set by \(B\) and \(C\) alone. The authors connect this to a classical fact: almost every real \(N\times N\) matrix is diagonalizable over \(\mathbb C\), so almost every dense real SSM is equivalent to a diagonal complex one. That is why diagonal SSMs became the standard choice.

\(a_t=0\) is a free document separatorno padding

Setting one decay to zero kills every entry of \(L\) that crosses that position, which makes \(M\) block diagonal. So sequences of different lengths can be concatenated into one long sequence, with no padding and no special masks. The same block decomposition splits a long sequence across GPUs: each GPU computes its chunk and passes one \(N\times P\) state to the next. For attention, the communication instead grows quadratically with the number of GPUs.

Closure under compositionN + P

The product of an \(N\)-semiseparable and a \(P\)-semiseparable matrix is \((N+P)\)-semiseparable, and so is their sum. So two SSMs chained together, or run in parallel and added, form a single SSM whose state sizes add.

A little attention goes a long way≈ 10%

The comparison uses a 350-million-weight, 48-layer model, scored by perplexity (lower means the model predicts text better). Pure Mamba-2 scores 8.60 and the Transformer baseline 8.68. Swapping 6 of the 48 layers for softmax attention gives 8.26. The authors' guess: the SSM layers compress context into a fixed state, while a few attention layers provide exact lookup of earlier tokens, which no fixed-size state can do.

V · If You Remember One Thing

The one thing to remember

A state space model with state size \(N\) is a lower-triangular matrix whose blocks below the diagonal all have rank at most \(N\). The recurrence and (softmax-free, masked) attention are just two ways to multiply by that matrix, and Mamba-2 gets its speed by mixing them blockwise so that nearly all the work is matrix multiplication.
