Paper of the day · ICML 2016

A3C

Asynchronous Methods for Deep Reinforcement Learning

Volodymyr Mnih, Adrià Puigdomènech Badia, Mehdi Mirza et al. · 2016 · arXiv:1602.01783

Instead of training a game-playing neural network on a stored memory of its past experience, the paper runs sixteen copies of the agent at once on one CPU. Each plays its own copy of the game and writes its updates into one shared set of weights. That alone keeps training stable, and the paper's best method built on it, A3C, was the strongest Atari agent of its time.

I · In 60 Seconds

Problemcorrelated data

In reinforcement learning (RL), an agent repeatedly sees the current state of a world (here, a frame of an Atari video game), picks an action, and receives a numerical reward. It learns to pick actions that maximise its total future reward. When the agent is a deep neural network trained by gradient descent, there's a snag: the frames one agent sees are consecutive moments of one game, so they are strongly correlated, and their distribution drifts as the agent's behaviour changes. Gradient descent expects roughly independent samples. Fed a correlated stream, it chases whatever happened most recently and can diverge.

The standard fix was the one used by DQN (DeepMind's 2015 "Deep Q-Network", the first network to learn Atari games from pixels): experience replay. The agent stores its last million transitions and trains on random samples from that memory. This costs memory, and it only works with off-policy algorithms, which can learn from data produced by an older version of the agent.

Idea16 threads, 1 θ

Run 16 agents in parallel CPU threads on one machine. Each has its own copy of the game and explores a little differently. Each thread plays 5 steps, computes a gradient from them, and writes it into one shared parameter vector \(\theta\) without locks. At any moment the threads are at different points in different games, so the stream of updates reaching \(\theta\) is far less correlated than a single agent's. Parallelism supplies the decorrelation that replay used to supply, with no memory buffer.

That makes on-policy methods usable, meaning methods that must learn from the current agent's own behaviour. The paper builds asynchronous versions of four classic algorithms. The best is A3C, asynchronous advantage actor-critic: one network outputs both a policy (action probabilities) and an estimate of how good the current state is.

Result623% · 4 CPU-days

The test is 57 Atari games, scored as a human-normalised score: 0% is random play and 100% is a professional human tester. Averaged over the games, A3C with a recurrent memory layer (an LSTM) reaches 623% after 4 days on 16 CPU cores. The best earlier agent (Prioritized DQN) reached 463.6% after 8 days on a GPU. The median game tells a more modest story: 112.6% vs 127.6%.

The same agent also learns 3D maze navigation from raw pixels and continuous robot control in a physics simulator. With 16 threads, the time to reach a fixed score falls by 12.5× to 24.1×, depending on the algorithm.

II · The Linear Algebra

MachineryThree matrices do the work

Three matrices explain why A3C works. The first is a stochastic matrix \(P\), which says how far a reward travels backwards in one update. The second is the softmax covariance \(\operatorname{diag}(\pi)-\pi\pi^{\top}\), which shapes every policy gradient. The third is the covariance \(\Sigma\) of the gradient samples in a batch: the direction \(\mathbf 1\) (the all-ones vector) is what decides whether averaging those samples helps.

The objects

\(\theta\in\mathbb R^{p}\)shared

Every network weight, flattened into one vector held in shared memory. The network is small: two convolutional layers and a 256-unit layer. It has two outputs. A policy head gives a vector of logits \(z(s)\in\mathbb R^{|\mathcal A|}\), one per action in the action set \(\mathcal A\) (up to 18 joystick moves), turned into probabilities \(\pi(\cdot\mid s)=\operatorname{softmax}(z)\). A value head gives a scalar \(V(s)\), the network's estimate of the future reward from state \(s\). All other layers are shared between the two heads.

\(\theta'\)per thread

Each thread copies \(\theta\) into its own \(\theta'\), plays \(t_{\max}=5\) steps with it, computes a gradient at \(\theta'\), and adds the step into the shared \(\theta\). By then other threads may have changed \(\theta\), so gradients are slightly stale.

\(R_t,\ \gamma\)\(\gamma = 0.99\)

The return is \(R_t=\sum_{k\ge0}\gamma^k r_{t+k}\), the rewards \(r\) from time \(t\) on, discounted by \(\gamma\in(0,1)\) so that later rewards count less.

1 · Returns are a Neumann series, and n-step returns use \(P^n\)

Fix the agent's behaviour and suppose there are finitely many states. Let \(P\) be the transition matrix: \(P_{ss'}\) is the probability that the next state is \(s'\) given the current state \(s\). It is row-stochastic: its entries are nonnegative and each row sums to 1. Let \(r\) be the vector of expected one-step rewards. Then the vector of state values satisfies a linear system:

$$V^{\pi}=r+\gamma P V^{\pi}\quad\Longrightarrow\quad V^{\pi}=(I-\gamma P)^{-1}r=\sum_{k\ge0}\gamma^kP^k r .$$

The inverse exists because \(\|P\|_\infty=1\) (the max row sum), so \(\|\gamma P\|_\infty=\gamma\lt1\). Every eigenvalue of \(\gamma P\) therefore has modulus at most \(\gamma\), and the Neumann series converges.

Learning never forms \(P\). It moves \(V\) towards a target built from observed rewards. A one-step target applies \(TV=r+\gamma PV\) once. An \(n\)-step target applies it \(n\) times:

$$T^nV=\sum_{k=0}^{n-1}\gamma^kP^kr+\gamma^nP^nV,\qquad T^nV-V^{\pi}=\gamma^nP^n\,(V-V^{\pi}).$$

So the error shrinks by a factor of \(\gamma^n\) in sup norm per target, not \(\gamma\). Seen another way, a reward reaches \(n\) earlier states per update instead of one. A3C uses this inside each 5-step segment: the last state of the segment gets a 1-step target and the first gets a 5-step target. The resulting advantage, meaning how much better the action taken turned out than the value predicted, is

$$A_t=\sum_{i=0}^{k-1}\gamma^i r_{t+i}+\gamma^kV(s_{t+k})-V(s_t),\qquad k\le t_{\max}=5.$$

2 · The softmax covariance: symmetric, PSD, kernel \(\mathbf 1\)

The actor half of actor-critic updates the policy along \(\nabla_\theta\log\pi(a_t\mid s_t)\,A_t\): make the action taken more likely if it beat expectation, less likely otherwise. The critic half is the value head that supplies \(V\). By the chain rule, every policy gradient passes through the logits, where the gradient for a sampled action \(a\) is

$$\frac{\partial\log\pi_a}{\partial z}=e_a-\pi,$$

with \(e_a\) the standard basis vector for action \(a\). Two facts about this random vector (random because \(a\sim\pi\)) carry the method:

$$\mathbb E_{a\sim\pi}[e_a-\pi]=0,\qquad \operatorname{Cov}(e_a-\pi)=\operatorname{diag}(\pi)-\pi\pi^{\top}=:J .$$

Mean zero. Subtracting any baseline that depends only on the state, such as \(V(s_t)\), leaves the expected gradient unchanged, but it can cut the variance a lot. That is why the update multiplies by \(A_t\) and not by the raw return.

\(J\) is a covariance matrix, so it is symmetric and positive semidefinite. It is also the Jacobian \(\partial\pi/\partial z\) of the softmax. It satisfies \(J\mathbf 1=\pi-\pi(\pi^{\top}\mathbf 1)=0\): adding a constant to every logit leaves the policy unchanged. If all \(\pi_a\gt0\), its rank is exactly \(|\mathcal A|-1\).

The same \(J\) shows up in the paper's entropy bonus. A term \(\beta H(\pi)\) with \(\beta=0.01\) is added to the objective, where \(H(\pi)=-\sum_a\pi_a\log\pi_a\) is high when the policy is spread out. It keeps the agent exploring and stops it locking into one action too early. Its gradient is

$$\nabla_zH=-J\log\pi .$$

Because \(J\mathbf 1=0\), only the deviation of \(\log\pi\) from its mean matters. The gradient vanishes exactly at the uniform policy.

Tiny example: three actions

\(\pi=(\tfrac12,\tfrac14,\tfrac14)\). Then \(J=\begin{pmatrix}\tfrac14&-\tfrac18&-\tfrac18\\-\tfrac18&\tfrac3{16}&-\tfrac1{16}\\-\tfrac18&-\tfrac1{16}&\tfrac3{16}\end{pmatrix}\). Every row sums to 0.

Eigenpairs: \(0\) on \((1,1,1)\); \(\tfrac14\) on \((0,1,-1)\); \(\tfrac38\) on \((2,-1,-1)\). The trace checks out: \(0+\tfrac14+\tfrac38=\tfrac58=\tfrac14+\tfrac3{16}+\tfrac3{16}\).

Entropy push: \(\log\pi=-\ln2\,(1,2,2)\), so \(-J\log\pi=\ln2\,(-\tfrac14,\tfrac18,\tfrac18)\approx(-0.17,\,0.09,\,0.09)\). It lowers the logit of the favourite action and raises the other two, and it lies entirely along the eigenvector \((2,-1,-1)\).

3 · Why parallel actors stabilise: the \(\mathbf 1\) direction of \(\Sigma\)

Take one coordinate of the gradient and let \(g_1,\dots,g_B\) be the \(B\) samples that feed one update, each with variance \(\sigma^2\). Collect their covariances in \(\Sigma\in\mathbb R^{B\times B}\), which is symmetric and PSD. The update uses their average, which is a projection onto \(\mathbf 1\):

$$\operatorname{Var}\Big(\tfrac1B\textstyle\sum_i g_i\Big)=\frac{\mathbf 1^{\top}\Sigma\,\mathbf 1}{B^2}.$$

If consecutive samples from one agent all have correlation \(\rho\), then \(\Sigma=\sigma^2\big((1-\rho)I+\rho\,\mathbf 1\mathbf 1^{\top}\big)\). Its spectrum is one large eigenvalue \(\sigma^2(1+(B-1)\rho)\) with eigenvector \(\mathbf 1\), and \(B-1\) small ones equal to \(\sigma^2(1-\rho)\) on \(\mathbf 1^{\perp}\). The correlation piles all the variance onto the exact direction the average measures:

$$\operatorname{Var}=\sigma^2\,\frac{1+(B-1)\rho}{B}\ \xrightarrow{\,B\to\infty\,}\ \rho\,\sigma^2 .$$

So adding more correlated samples never pushes the variance below the floor \(\rho\sigma^2\). Samples from \(K\) independent games instead make \(\Sigma\) block-diagonal, and the variance falls like \(1/K\).

Tiny example

\(B=16\), \(\rho=0.9\). One agent: \(\operatorname{Var}=\sigma^2(1+15\cdot0.9)/16\approx0.91\,\sigma^2\), so 16 samples are worth about 1.1 independent ones. Sixteen threads contributing one sample each: \(\Sigma=\sigma^2I\) and \(\operatorname{Var}=0.0625\,\sigma^2\), worth all 16.

The paper makes this argument in words ("less correlated in time"). The covariance computation above is the standard way to make it precise, and the first interactive below shows it. Asynchrony adds one more effect: the sequence of updates that hits \(\theta\) interleaves the threads, so consecutive steps of the optimiser come from different games.

4 · The optimiser: a shared diagonal preconditioner

Updates use RMSProp, which divides each coordinate of the gradient \(\Delta\theta\) by a running root-mean-square of its past values. All operations are elementwise:

$$g\leftarrow\alpha g+(1-\alpha)\,\Delta\theta^{2},\qquad \theta\leftarrow\theta-\eta\,D^{-1/2}\Delta\theta,\quad D=\operatorname{diag}(g+\epsilon).$$

Here \(\eta\) is the learning rate, \(\alpha=0.99\) the averaging rate, and \(\epsilon\) a small constant that keeps the division safe. \(D\) is a positive-definite diagonal preconditioner that rescales each coordinate's step. In shared RMSProp, the statistics \(g\) live in shared memory, so all 16 threads estimate one \(D\) together. Across 50 random learning rates and initialisations, this variant was clearly the most robust, ahead of per-thread RMSProp and of momentum SGD.

IV · Cool Things

FindingsFrom the paper's tables

More than 16× faster with 16 threads24.1×

For one-step Q-learning, the time to reach a reference score drops 3.0× with 2 threads and 24.1× with 16 (averaged over seven games). That is superlinear: more threads also need less total experience to learn. The authors attribute this to the threads' varied exploration reducing the bias of one-step targets. A3C itself scales sublinearly (12.5× at 16 threads).

A CPU beat the GPUs1 day ≈ 8 days

After a single day on 16 CPU cores, the feed-forward A3C (no memory layer) averages 344.1%, level with Dueling Double DQN's 343.8% after 8 days on a GPU. Gorila, an earlier distributed agent, used 100 machines plus 30 parameter servers.

Writes without locks still convergeHogwild!

Threads add into \(\theta\) with no locking, in the style of Hogwild! (a 2011 lock-free parallel SGD scheme). Occasionally they overwrite each other, and every gradient is computed at a slightly stale copy. A classic result (Tsitsiklis, 1994) says Q-learning still converges with outdated information, provided stale information is eventually discarded.

Hard to break with a bad learning rate50 runs

The authors drew 50 learning rates log-uniformly from \(10^{-4}\) to \(10^{-2}\), each with a fresh random initialisation. A3C does well across a wide band of them, and in that band there are virtually no runs scoring 0. Once it starts learning, it doesn't collapse.

V · If You Remember One Thing

The one thing to remember

Gradient samples from one agent are correlated, so averaging more of them stalls at a variance floor of \(\rho\sigma^2\). Samples from many agents playing separate games are independent, so their variance keeps falling like \(1/K\). That alone replaces experience replay and lets plain actor-critic train deep networks on a CPU.
